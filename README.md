# 🏰 塔防 · Tower Defense

零依赖、纯 HTML5 Canvas 实现的经典塔防游戏。三种防御塔、四种敌人、20 波关卡，支持多地图切换。

## 🗺️ 6 张可选地图

| # | 地图名称 | 特点 | 推荐战术 |
|---|---------|------|---------|
| 1 | **🏔️ S型蛇道** | 经典蛇形路线，中等长度 | 新手入门，均衡布局 |
| 2 | **🏗️ U型回廊** | U形弯道围绕中心区 | 适合冰塔封锁走位 |
| 3 | **🐍 蛇之道** | 超长蛇形贯穿全图 | 考验长期资源规划 |
| 4 | **🌀 螺旋回廊** | 绕中心盘旋向内 | 炮塔发挥巨大威力 |
| 5 | **🌊 双河汇流** | 宽阔蛇形上下两层 | 充足空间布置双层防线 |
| 6 | **⚡ 闪电突袭** | 快速直线+对角线穿插 | 节奏紧凑，箭塔主场 |

点击地图卡片即可切换并开始游戏。

## 🎮 游戏玩法

- **建造**：选择左侧塔类型 → 点击草地绿色格子放置
- **升级**：点击已建造的塔 → 点击升级按钮（最多 3 级）
- **回收**：右键点击塔 / X 键快速回收 / 回收模式按钮 / 回收全部按钮
  - 返还投入金币的 **70%**
- **开始波次**：点击 "开始下一波" 按钮或按空格键

### 快捷键
| 按键 | 功能 |
|------|------|
| `1` | 选择箭塔 |
| `2` | 选择炮塔 |
| `3` | 选择冰塔 |
| `空格` | 开始下一波 |
| `S` | 加速/减速 |
| `X` | 回收选中的塔 |
| `ESC` | 取消选择 |
| `右键` | 回收/取消 |

## 🏗️ 防御塔

| 塔类型 | 描述 | 特色能力 |
|--------|------|----------|
| 🔵 **箭塔** | 高射速单体攻击 | 持续伤害输出，适合前期 |
| 🟠 **炮塔** | 低射速范围爆炸 | 溅射伤害，后期清兵利器 |
| 🟣 **冰塔** | 减速并冰冻敌人 | 降低敌人移速，配合其他塔使用 |

|------|----|------|---------|---------|
| 🔴 **小兵** | 30 | 60 | 6金 | 每波都有 |

## 💾 使用说明

直接双击 `index.html` 在浏览器中打开即可游玩，无需服务器或安装任何东西。
